API 使用

🔌 标准化 C ABI

基于标准 C 应用程序二进制接口，支持从任何语言调用

🖥️ 6 大平台覆盖

Windows、Linux、macOS、Android、HarmonyOS、iOS 全平台动态库编译

⚡ 极致性能

Rust 实现，极短 GC 停顿、极低内存占用、原生并发支持

🌐 内置 Fetch API

原生支持 HTTP/HTTPS 下载，带 TLS 指纹伪装

📦 Node.js 兼容

内置 Node.js 标准库模块（assert、buffer、crypto、events、http、net、stream、url、zlib 等）

🔄 ES Modules

原生支持 ES Module 导入导出语法

📦 FFI 和 .node API

原生支持同步/异步 FFI 和兼容 .node 的 node 加载
