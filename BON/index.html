标准库

完全兼容 JSON

所有合法 JSON 都是合法 BON。BON 不引入新格式，只在 JSON 之上增加语法糖。

编译期求值，零运行时

所有逻辑在解析时完成，输出纯 JSON，宿主程序零改动。

确定性

图灵不完备，无循环、无随机数、无系统时间，相同源码输出一致。

模板系统

消除重复配置，模板展开为独立的深拷贝副本，互不干扰。

类与继承

可复用的数据结构，支持单继承、计算属性和方法调用。

标准库

字符串、数组、对象操作，std.map、std.filter、std.reduce 等纯函数。
