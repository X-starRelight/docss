核心依赖 ​

SenRi FFI 自身零原生依赖，在 Node.js 上依赖以下可选包：

Node.js 后端 ​

  • koffi — Node.js 的 FFI 库
    • 提供 C 类型定义、动态库加载、函数绑定
    • 通过 peerDependencies 声明为可选依赖

TypeScript 构建 ​

  • TypeScript — 类型安全的 JavaScript 超集
  • typescript — TypeScript 编译器
  • types/node — Node.js 类型定义

支持的运行时 ​

SenRi FFI 支持以下 JavaScript 运行时：

运行时说明
KossJS嵌入式 JavaScript 运行时，内置 FFI 支持
Bun快速的全能 JavaScript 运行时，内置 FFI 支持
Node.js广泛使用的 JavaScript 运行时，通过 koffi 提供 FFI 支持
