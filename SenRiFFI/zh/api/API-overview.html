API 概览 ​

SenRi FFI 导出的公共 API 一览。

ts
import {
  // 核心
  Library,
  types,

  // 类型构造器
  pointer,
  array,
  struct,

  // 指针操作
  Pointer,
  callback,

  // 内存管理
  alloc,
  free,
  addressOf,
  errno,
  strerror,

  // 错误
  FFIError,
  FFITypeError,
} from '@tt23xrstudio/senri_ffi';

API 分类 ​

Library — 库加载与函数绑定 ​

导出说明文档
Library.load(path)加载原生共享库 (.dll/.so/.dylib)Library.load()
lib.func(name, retType, argTypes, options?)绑定 C 函数 — 同步调用（带缓存）func()
lib.funcAsync(name, retType, argTypes)绑定 C 函数 — 异步调用，返回 PromisefuncAsync()
lib.close()同步关闭库并释放资源close()
lib.closeAsync()异步关闭库，等待 Worker 和异步任务完成closeAsync()

详见 Library
